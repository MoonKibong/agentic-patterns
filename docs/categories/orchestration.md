# Orchestration Patterns

Orchestration patterns define multi-agent and multi-session coordination: how work, handoffs, and
workflow state are managed across agents or sessions.

Use orchestration patterns when a task spans more than one agent, session, or interruption and the
workflow state must survive outside any single chat.

## Current Patterns

- [Durable Session State](../../patterns/orchestration/durable-session-state.md): keep agent
  workflow state outside transient chat memory.
