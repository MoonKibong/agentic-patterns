# オーケストレーションパターン

Orchestration pattern はマルチエージェントおよびマルチセッションの調整を定義します。つまり、複数のエージェントやセッションにまたがって、作業、引き継ぎ、ワークフロー状態をどう管理するかを扱います。

タスクが複数のエージェント、セッション、または中断にまたがり、ワークフロー状態が単一のチャットの外でも維持されなければならない場合に使用します。

## 現在のパターン

- [永続セッション状態 (Durable Session State)](../../../../patterns/orchestration/durable-session-state.md): エージェントのワークフロー状態を一時的なチャットメモリの外に保持します。
