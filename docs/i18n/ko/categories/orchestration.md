# 오케스트레이션 패턴

Orchestration pattern은 멀티 에이전트와 멀티 세션 조정을 정의합니다. 즉, 여러 에이전트나 세션에 걸쳐 작업, 인계, workflow state를 관리하는 방식입니다.

작업이 둘 이상의 에이전트, 세션 또는 중단에 걸쳐 있고 workflow state가 어떤 단일 chat 밖에서도 유지되어야 할 때 사용합니다.

## 현재 패턴

- [지속 세션 상태 (Durable Session State)](../../../../patterns/orchestration/durable-session-state.md): agent workflow state를 일시적인 chat memory 밖에 보관합니다.

## 패턴 아이디어
