# 编排模式

Orchestration pattern 定义多代理和多会话协调：如何在多个代理或会话之间管理工作、交接和工作流状态。

当任务跨越多个代理、会话或中断，且工作流状态必须在任何单次聊天之外保留时，请使用编排模式。

## 当前模式

- [持久会话状态 (Durable Session State)](../../../../patterns/orchestration/durable-session-state.md)： 将代理工作流状态保存在临时聊天记忆之外。
